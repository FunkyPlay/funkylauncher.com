Starfield crashing with mods: what to do

If Starfield crashes or won't start after you install mods, the cause is most often one of a few simple things. Go through them in order — it is usually enough.

The Nova Nights modlist is still in testing.

Check in this order

  • Game version. The mods are made for Starfield 1.16.244 with the Shattered Space expansion. If the game updated, the mod loader and many mods stop working until a new modlist version is out. Turn off the game's auto-update and don't update the game. If the error mentions a "master file not found", most likely Shattered Space is missing or the game version is wrong.
  • How you start. Start the game only with the PLAY button in Funky Launcher. If you start it with a shortcut, the mods won't load, and the loader files left in the game folder can break the launch.
  • First launch. After the first launch, after a graphics driver update and after a game update, Starfield rebuilds its shaders: the main menu and the first load can take a few minutes, with some stutter in the first minutes. Don't close the game, just wait.
  • Game files. In the launcher open "Install and verify" → "VERIFY FILES". If the game files differ from the needed version, the launcher will say so.
  • Antivirus. It may have deleted or blocked the mod loader file (sfse_loader.exe) or dll files. Add the game folder and the modlist folder to your antivirus exclusions — only if you downloaded the launcher from our website; don't turn the antivirus off completely — and press "REPAIR", or reinstall the modlist through the launcher.
  • Driver and launcher. Update the launcher to the latest version and your graphics driver. If heavy stutter or a crash on loading appeared after a driver update: close the game, delete the Pipeline.cache file in %LOCALAPPDATA%\Starfield and start the game again. The first launch after that will take longer. Your saves and mods are not affected.
  • HD planets. If your graphics card has 8 GB of memory or less, it is better not to turn on this optional pack.

If it didn't help

Right after a failed launch, press "Make an error report" on Home: an archive appears on your desktop. Send it to the support chat in the launcher and describe in words what happens: the game closes at once, on the splash screen or during play. If the crash happened in the game, also attach the crash log from the folder Documents\My Games\Starfield\SFSE\Crashlogs (the file with the date and time of the crash). This helps find the cause much faster. The report contains file names and paths; send it only to the launcher's support chat.

How we work on crashes

Every day we go through player reports, update mods and write our own fixes, so the modlist gets more stable with each update.

The game crashes right after launch. Where do I start?

Check the game version (1.16.244 with Shattered Space) and that you start the game with the PLAY button in the launcher. Then press "VERIFY FILES" in "Install and verify".

The game crashed after a game update. What now?

Mods are made for a specific game version. Wait for a new modlist version: it will appear in the launcher by itself. It is better to turn off the game's auto-update.

The main menu is slow and there is stutter in the first minutes. Is it a crash?

No, it is shader preparation, which happens after the first launch or a driver or game update. Wait a few minutes and don't close the game.

How do I send an error report?

On Home press "Make an error report"; the archive is saved on your desktop. Send it to the support chat in the launcher and describe what happens after you press PLAY.
