FAQ

Frequently asked

Is it really free?

Yes. The launcher, modlists and support are free. Only Pro with extra tools will be paid — everything works without it.

Do I need Nexus Premium?

No. A free Nexus Mods account works: press "Slow download" for each mod, it takes longer. With Premium everything downloads by itself.

Windows says "Unknown publisher". Is it safe?

The launcher isn't code-signed yet. The code is open on GitHub, the file is built from it by GitHub and has a checksum. Click "More info" → "Run anyway".

Will my game be changed?

No. The modlist goes into its own folder and runs from there. Your normal game stays as it was.

What if it doesn't start?

Press "Collect error report" in the launcher and send it to @FunkyLauncherBot — we'll sort it out.
