FAQ

Frequently asked

Is it really free?

Yes. The launcher and all modlists are free, and so is support.

Do I need Nexus Premium?

No. A free Nexus Mods account works — you press "Slow download" for each mod, and it takes longer. With Premium everything downloads by itself.

Windows says "Unknown publisher". Is it safe?

The launcher isn't code-signed yet. The code is open on GitHub, the file is built from it on GitHub's servers, and you can check it against the checksum. Click "More info" → "Run anyway".

What does the launcher do to my game folder?

The modlist goes into its own folder. The launcher puts only a few small loader files into the game folder (6 for Cyberpunk 2077, 2 for Starfield and Fallout 4), because the mods need them to run. "Restore clean game" removes them.

What if it doesn't start?

Press "Make an error report" in the launcher and send it to @FunkyLauncherBot — we'll sort it out.

Which games are next?

Neon Nights (Cyberpunk 2077), Nova Nights (Starfield) and Atomic Nights (Fallout 4) are out, GTA V Enhanced is in progress.
