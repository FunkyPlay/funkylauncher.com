Funky Launcher — help

How to remove mods and restore a clean game

If you installed mods with Funky Launcher, getting a clean game back is simple: open the Library, find the installed modlist and press "Restore clean game". It works for all three games.

What the button does

  • The mods live in a separate modlist folder, and the launcher puts only a few small loader files into the game folder. The "Restore clean game" button removes them from the game folder.
  • In Cyberpunk 2077 these are 6 small files (CET, RED4ext, redscript), in Starfield the SFSE loader (2 files), in Fallout 4 the F4SE loader (2 files).
  • The mods and the modlist themselves stay in their own folder: you can play the clean game as usual and come back to the mods later.

How to do it

  • Close the game.
  • Open Funky Launcher and go to the Library.
  • On the installed modlist press "Restore clean game".
  • Start the game with its regular shortcut: it is now without mods.

If you want to remove the modlist completely

The modlist folder is separate: it is the folder you chose during installation. If you need to free up space, close the launcher and the game and delete that folder by hand. First press "Restore clean game", so that no loader files are left in the game folder. Before deleting, save the saves you need: for Starfield and Fallout 4 the modlist's saves are kept inside the modlist folder (the profiles folder, then saves); your regular game saves are not touched by the modlist. In Cyberpunk 2077 the saves are kept in the regular folder (Saved Games\CD Projekt Red\Cyberpunk 2077), and deleting the modlist folder does not affect them; only the mod settings, which live in the modlist folder, are lost. A save made with the modlist may load in the clean game with a warning or without the mods' items and clothes. Before deleting, copy your saves folder to a safe place.

Good to know

  • You don't need to reinstall the game: the clean game comes back with the button in a few seconds.
  • If the game doesn't start afterwards or you want to check the files, open "Install and verify" in the launcher and press "VERIFY FILES".
  • Saves made with mods may not load in the clean game or may work with errors: it is better to start a new game or use a save made without mods.

Do I need to delete the game to remove mods?

No. The "Restore clean game" button is enough: it removes the loader files from the game folder.

Will my mods disappear after I press the button?

No. The mods and the modlist stay in their own folder. The game simply starts without them.

How do I remove just one mod?

The mods in a modlist are chosen to work together, so it is better not to remove single mods by hand: it may break the modlist. If a particular mod bothers you, write to the support chat in the launcher.

What if the game doesn't start after restoring a clean game?

Open "Install and verify" in the launcher and press "VERIFY FILES". If that doesn't help, press "Make an error report" on Home and send it to the support chat.
